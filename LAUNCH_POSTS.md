## 💬 Comments/Replies Templates

### When someone asks "How does it work?"
```
It scrapes the company website, jobs pages, and searches for news/funding. Then AI (Gemini) analyzes all that data to:

1. Score buying intent based on hiring, funding, news signals
2. Identify their biggest strategic gap
3. Generate personalized messages referencing that gap

Takes about 70 seconds per company!
```

### When someone asks "Is it free?"
```
Yes! Free tier includes:
• 1000 research requests/month
• All features unlocked
• No credit card required

Uses Gemini's free API tier (1500 requests/day) so it's genuinely free for normal usage.
```

### When someone asks "What's the tech stack?"
```
• Frontend: Next.js 14 + Tailwind
• Backend: FastAPI (Python)
• AI: Google Gemini API
• Search: Tavily API
• Hosting: Vercel (frontend) + Railway (backend)

Went from idea to deploy in 7 days!
```
